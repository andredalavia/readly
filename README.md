# Readly

Aplicativo para desenvolver e acompanhar o hábito de leitura.

## Stack

- React + TypeScript + Vite
- Tailwind CSS
- Lucide React
- Persistência local no MVP inicial

## Desenvolvimento

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Estado do MVP

Primeira etapa: biblioteca pessoal, registro de progresso por página, sessões de leitura cronometradas, metas e estatísticas locais. A camada multiusuário e os recursos sociais dependem da configuração de um projeto Supabase.
